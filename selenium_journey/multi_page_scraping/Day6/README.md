# Day 6 — JSON Export and Verification with Selenium

## Overview

Day 6 of my Python Selenium web-scraping journey focuses on exporting scraped book records to **JSON**, reading them back, and verifying data integrity. I also integrated JSON export into my existing multi-page book scraper alongside CSV export.

## Files

```text
Day6/
├── book_scraper.py   # Scrapes books across up to three pages and exports CSV + JSON
├── json_test.py      # Practices JSON writing, reading, and verification
├── books.json        # JSON output (generated by the scripts)
└── README.md         # Project documentation
```

> `book_scraper.py` also generates `books.csv` when it runs. Both scripts use the filename `books.json`, so running either script can overwrite that file with its own dataset.

## What I Learned

- JSON objects (`{}`) and arrays (`[]`)

- `json.dump()` for writing JSON files
- `json.load()` for reading JSON files
- `indent=4` for readable formatting
- `ensure_ascii=False` for preserving Unicode characters such as `£`
- UTF-8 encoding for JSON files
- Comparing loaded records with original data to verify integrity
- Exporting the same Selenium records to CSV and JSON

## How the Selenium Scraper Works

1. Opens the [Books to Scrape](https://books.toscrape.com/) practice website using Chrome and Selenium.
2. Extracts each book's **title**, **price**, and **availability**.
3. Checks that required fields are not empty.
4. Follows the **Next** link to process up to three pages.
5. Stores valid records as a list of Python dictionaries.
6. Writes collected records to `books.csv` and `books.json`.
7. Reads the output files back to verify the exported records.

The three-page exercise is expected to collect **60 books** when all three pages load successfully and their records are valid. Actual results depend on successful scraping.

## Requirements

- Python 3
- Google Chrome
- Selenium

Install Selenium:

```bash
python -m pip install selenium
```

Python's `csv` and `json` modules are included in the standard library. A recent Selenium version can manage the Chrome driver automatically in supported environments.

## Run the Programs

From the `Day6` folder:

```bash
python json_test.py
```

Run the Selenium scraper:

```bash
python book_scraper.py
```

The scraper creates or overwrites `books.csv` and `books.json` in the current working directory.

## Data Verification

After reading JSON back into Python, I compare the full records rather than only their counts:

```python
if all_books == records:
    print("JSON verification successful.")
else:
    print("JSON verification failed.")
```

A matching record count alone cannot detect incorrect titles or prices. Full list equality also checks record order.
